# NalaServux

Servux for Paper and Purpur 26.2, built for the Nala Mc server.

It is a port of [Servux](https://github.com/sakura-ryoko/servux) (branch `LTS/26.2`), with the Syncmatica and JEI server sides.
The code follows upstream file by file. Only the parts that depend on Fabric or on mixins are different.
